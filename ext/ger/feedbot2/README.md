# Feed Bot 2 - Special edition for Wereldfietser.nl

This phpBB extension enables you to read any RSS, ATOM or RDF feed. It looks for new items every half hour and post them to a specified forum.

## Installation

* Copy the contents of the extension to phpBB/ext/ger/feedbot2
* Go to "ACP" > "Customise" > "Extensions" and enable the "Feed Bot 2" extension.
* Go to the Extensions tab and find the "Feed bot 2" settings. Setup as explained there.
